Phase 6 — The contamination experiment

One simple, pre-registered macro-reactive rule, evaluated under four data regimes. Pre-registration matters: the rule is written down before the results are seen, so the experiment measures contamination rather than the search for a good-looking answer.

Exit criterion: state the size of each contamination source in basis points or Sharpe units. planned
This is the only phase where strategy code is permitted, and only as a measurement instrument. Scope creep into strategy building is rated high-likelihood in the risk register — the rule here is deliberately dull because an interesting one would invite tuning.
