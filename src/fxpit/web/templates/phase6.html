The design

{{ m.card_open('Why the dishonest variants exist', 'recorded', '') }}

The project deliberately constructs backtests it knows to be wrong. They are not strawmen — each is a faithful reproduction of a mistake that appears in real research, and the gap it opens against variant A is the quantity being estimated.

A single honest backtest would yield one number with nothing to compare it to. A Sharpe of 0.3 is uninterpretable alone. The contribution comes entirely from the differences, which requires running the contaminated arms on purpose.

An event is only traded when every variant can price it. Otherwise the arms would compare different event sets and the differences would partly measure sample composition rather than contamination.

{{ m.card_close() }} {{ m.card_open('The surprise measure is synthetic, and labelled', 'recorded', '') }}

There is no free source of historical consensus forecasts, so a genuine "actual vs expected" surprise cannot be constructed. The substitute is the headline change minus its trailing twelve-release mean — deviation from recent trend, not deviation from expectation, and those are different things.

Why this does not invalidate the experiment. The same construction is used in all four variants, so its imperfection is a constant across the comparison. It shifts every level together and leaves the differences intact. A shared flaw in a shared input cannot manufacture a difference between arms.

{{ m.card_close() }} {{ m.card_open('What this does not produce', 'recorded', '') }}

A profitable strategy — stated plainly so it is not a disappointment later. The output is four Sharpe ratios and their differences: a price list for hindsight, denominated in Sharpe units. That is the artefact worth showing someone, not the rule.
