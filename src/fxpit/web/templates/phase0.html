Phase 0 — Acceptance tests

Write the tests before the pipeline. A test written after the pipeline encodes what the pipeline does; a test written before it encodes what the pipeline must do. That distinction matters most for look-ahead bias, because a contaminated pipeline produces no errors — only better-looking results.

Exit criterion: each test's failure mode is explainable in one sentence. ✓ met
