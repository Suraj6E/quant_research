Phase 2 — Cleaning as a reversible layer

Each flag is an independent, re-runnable detector writing rows to tick_flag. Raw is never modified. If a detector turns out to be wrong you delete flags and re-run — you do not re-download 300 GB.

Exit criterion: for any instrument-day, produce a list of every tick that was flagged and why. planned

Taxonomy

{{ m.card_open('Why flags live in a separate table', 'recorded', '') }}

Two reasons, both structural: the taxonomy grows as new pathologies are found, and one tick can carry several flags at once. Columns on tick_raw would force a schema migration for every discovery and could not represent overlap.

Bars

{{ m.card_open('Materialised, never destructive', 'recorded', '') }}

Bars are materialised views over tick_raw, built as both bid-bars and ask-bars, never mid-only. A feed that forces an assumed spread is how backtests lie, and mid-price collapse is one of the four contamination sources Phase 6 exists to measure — so collapsing here would destroy the experiment before it runs.
